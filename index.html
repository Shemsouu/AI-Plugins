Installation

Trois commandes, et c'est réglé

Le système de plugins de Claude Code se pilote depuis la session. Les skills existent aussi en simple dossier ~/.claude/skills/.

ÉTAPE 01

Ajouter un marketplace

Le directory officiel est disponible par défaut. Pour un marketplace communautaire, il faut d'abord l'ajouter.

❯/plugin marketplace add obra/superpowers
ÉTAPE 02

Installer le plugin

La syntaxe est toujours nom@marketplace. Sans marketplace précisé, Claude Code cherche dans ceux déjà ajoutés.

❯/plugin install superpowers@claude-plugins-official
ÉTAPE 03

Alternative npm / npx

Certains outils sont des CLI autonomes : ils s'installent hors du système de plugins et restent disponibles partout.

❯npx claude-code-templates@latest
Traçabilité

Sources & méthode

Tout ce qui est affiché vient d'une source consultable. Les chiffres sont datés.

Transparence. Reddit a bloqué l'accès direct depuis cette machine (HTTP 403, bot-check), y compris via les lecteurs alternatifs : seuls les titres et extraits indexés des threads ont servi de signal. Les compteurs d'installations proviennent d'une revue publiée en novembre 2026 ; les étoiles GitHub sont exactes, sauf mention « ≈ » (valeurs arrondies par le badge Shields). Le directory officiel liste 317 entrées dans son manifeste ; la revue de novembre annonçait 276 plugins officiels et 2 307 communautaires — l'écart vient de la date et du périmètre du relevé. Aucune commande n'a été inventée : les /plugin install sont issues des manifestes marketplace.json, les commandes npm des paquets réellement publiés.
